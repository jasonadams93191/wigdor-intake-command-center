# Wigdor Intake Command Center

Lightning Web Component mockup for Wigdor LLP — depicts the deployable outcome of a custom LWC inside Salesforce Lightning Experience.

Three views (Pipeline / Dashboard / Performance) over the Intake lifecycle, with a shared filter store, lifecycle strip, conversion funnel, and slide-in detail drawer.

Built by [Advocate Cloud Solutions](https://advocatecloudsolutions.com).

This is a static mockup — no Salesforce backend is wired. Open `index.html` directly in a browser to view.
