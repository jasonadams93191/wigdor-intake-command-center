Architecture
One object, three views Both legacy dashboards (Referral and Partner Intake Summary) read the same Intake records. Pipeline shows what is in flight right now. Dashboard shows the period KPIs. Performance shows where the funnel leaks. Switching between them never reshapes filters or reloads data.
Lifecycle Bar
End-to-end visibility on every page The strip below every page shows every intake stage end-to-end with live counts. Click any stage to drop into the records sitting in that stage on the Pipeline page. It is the visual that proves these are not separate dashboards — it is one pipeline with different lenses.
